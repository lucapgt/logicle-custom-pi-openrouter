# Custom Logicle features

This branch contains the source-level customizations used by the Logicle deployment:

- OpenAI provider support retained.
- OpenRouter provider with dynamic model discovery.
- Generic OpenAI-compatible provider for local/self-hosted LLMs.
- Satellite/Pi reverse-inference and tool-use bridge.
- Persistent Light / Dark / System theme selector.

The Basic CI workflow is expected to run on every push to this branch.
